# Консольный набор утилит (Toolkit CLI)

Лабораторная работа №1 по программированию на Python. Приложение представляет собой пакет утилит командной строки (CLI),
объединяющий изолированное вычислительное ядро калькулятора выражений и конвертер физических величин.

Код полностью написан на чистом Python без использования встроенных функций `eval()`, `exec()` или сторонних библиотек
парсинга выражений.

## Архитектурная структура проекта

Проект спроектирован с жестким разделением вычислительной логики и интерфейса взаимодействия с пользователем:
```
lab_01/
├── pyproject.toml      # Конфигурация проекта (настройки путей для pytest и правил линтера ruff)
├── README.md           # Документация проекта с инструкциями по запуску и тестированию
├── src/
│   └── toolkit/
│       ├── __init__.py # Маркер Python-пакета (сообщает интерпретатору, что папка является модулем)
│       ├── __main__.py # Точка входа CLI (разбирает аргументы командной строки через argparse)
│       ├── calculator.py # Изолированное ядро калькулятора (токенизация, валидация и расчет)
│       ├── converter.py  # Изолированное ядро конвертера физических величин
│       └── errors.py     # Модуль централизованной обработки ошибок (вывод в stderr, код возврата 2)
└── tests/
    └── test_toolkit.py # Набор автоматических тестов для pytest
```

## Инструкция по запуску и примеры

Все команды выполняются из корневой директории проекта (`lab_01`) при активированном виртуальном окружении `.venv`.

### 1. Калькулятор выражений (`calc`)
Вычисляет математические выражения с поддержкой целых/вещественных чисел, унарных знаков и соблюдением приоритетов:
```bash
python -m toolkit calc "-2 * -3 + 10 / 4"
```

### 2. Конвертер величин (`convert`)
Выполняет взаимный перевод единиц длины, массы и температуры в рамках совместимых групп (регистр букв значения не имеет):
```bash
python -m toolkit convert 1.5 --from KG --to g
```

### 3. Получение встроенной справки (`--help`)
```bash
python -m toolkit --help
```

## Тестирование и проверка кодстайла

Для запуска автоматической проверки проекта на соответствие критериям оценивания используются следующие команды:

```bash
# Запуск 24 автоматических тестов ядра и CLI
python -m pytest

# Проверка оформления кода и аннотаций типов линтером
python -m ruff check .
```
