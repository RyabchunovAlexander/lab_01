# Toolkit — калькулятор и конвертер

Лабораторная работа №1 по предмету "Программирование на Python". Программа представляет собой пакет утилит командной строки (CLI) для математических вычислений и конвертации физических величин.

## Что делает программа

- **Калькулятор** — вычисляет инфиксные математические выражения без использования `eval()`.
- **Конвертер** — выполняет взаимный перевод единиц длины, массы и температуры.

## Установка и подготовка

```bash
# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка пакета в режиме редактирования
pip install -e .
```

## Использование

### 1. Калькулятор выражений (`calc`)

```bash
python -m toolkit calc "2+3*4"         # 14
python -m toolkit calc "10 / 4"        # 2.5
python -m toolkit calc "-2 * -3"       # 6
python -m toolkit calc "1+-2"          # -1
```

**Поддерживает:**
- Целые и вещественные числа (`int` и `float`).
- Бинарные операции: `+`, `-`, `*`, `/`.
- Унарные `+` и `-` перед числами (например, `-2 * -3`).
- Игнорирование пробелов между токенами выражений.
- Строгое соблюдение математического приоритета `*` и `/` над `+` и `-`.

### 2. Конвертер величин (`convert`)

```bash
python -m toolkit convert 1000 --from mm --to m     # 1.0
python -m toolkit convert 1.5 --from kg --to g       # 1500.0
python -m toolkit convert 0 --from c --to f          # 32.0
python -m toolkit convert -273.15 --from c --to k    # 0.0
```

**Поддерживает:**
- Длина: `mm`, `cm`, `m`, `km`.
- Масса: `g`, `kg`.
- Температура: `c`, `f`, `k`.
- Независимость от регистра символов (например, `KG` и `kg` эквивалентны).
- Защита от конвертации между несовместимыми группами (например, массы в длину).
- Строгий запрет на ввод температуры ниже абсолютного нуля.

### 3. Интерактивная справка

```bash
python -m toolkit --help
```
